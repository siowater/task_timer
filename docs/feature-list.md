# 機能一覧 (Feature List)

## 概要
本ドキュメントは、Hierarchical Time Tracker App の機能を一覧化したものである。
参照: [requirements.md](./requirements.md)

---

## 1. カテゴリー管理

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-001 | カテゴリー一覧表示 | ルートまたは親カテゴリー直下のカテゴリー一覧を表示 | 高 |
| F-002 | カテゴリー作成 | 新規カテゴリーを追加（Level 4 では非表示/無効化） | 高 |
| F-003 | カテゴリー削除 | 空のカテゴリーのみ削除可能。子カテゴリーまたはタスクが存在する場合は削除不可 | 高 |
| F-004 | カテゴリードリルダウン | カテゴリーをタップして子階層へ遷移 | 高 |
| F-005 | カテゴリー並び替え | 同一階層内で Drag & Drop による並び替え | 中 |

---

## 2. タスク管理

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-006 | タスク一覧表示 | ルートまたはカテゴリー直下のタスク一覧を表示（アクティブ＋アーカイブ） | 高 |
| F-007 | タスク作成 | 新規タスクを追加（アクティブ20個上限） | 高 |
| F-008 | タスク削除 | タスク削除時、紐づく稼働履歴も物理削除 | 高 |
| F-009 | タスクアーカイブ（完了） | タスクを完了済みにし、20個上限から除外 | 高 |
| F-010 | タスク復元 | アーカイブ済みタスクをアクティブに復元（20個未満時のみ） | 高 |
| F-011 | タスク並び替え | 同一階層内で Drag & Drop による並び替え | 中 |
| F-012 | アーカイブタスク表示 | リスト下部に「完了済み」としてグレーアウト表示 | 高 |

---

## 3. タイマー・計測

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-013 | タイマー開始 | タスク単位で Start。複数タスク同時稼働可 | 高 |
| F-014 | タイマー停止 | タスク単位で Stop。経過時間をセッションログに記録 | 高 |
| F-015 | 経過時間表示 | 計測中のタスクの経過時間をリアルタイム表示 | 高 |
| F-016 | 24時間上限処理 | 1回の計測が24時間を超えた場合、24時間で丸めて記録し Toast 表示 | 高 |
| F-017 | サスペンド/タスクキル対応 | startTime を保持し、アプリ復帰時に差分計算で経過時間を算出 | 高 |

---

## 4. 稼働履歴・ログ

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-018 | セッションログ記録 | いつ・どのタスクを・何分行ったかを記録 | 高 |
| F-019 | 日またぎログ分割 | 0時をまたぐ場合、前日分と当日分の2レコードに分割 | 高 |
| F-020 | 期間ビュー（今日） | 今日の稼働実績を閲覧 | 高 |
| F-021 | 期間ビュー（今週） | 今週の稼働実績を閲覧 | 高 |
| F-022 | 手動時間入力 | 手動で時間を追加（日またぎ時も分割処理） | 高 |
| F-023 | 履歴編集 | 過去のセッションログを編集 | 中 |
| F-024 | 履歴削除 | 過去のセッションログを削除 | 中 |

---

## 5. バリデーション

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-025 | 入力必須チェック | 空文字・空白のみを禁止 | 高 |
| F-026 | 時間整合性チェック | 未来日付禁止、開始>終了禁止、負の時間禁止 | 高 |
| F-027 | アクティブタスク上限チェック | 新規追加・復元時に20個以内か判定 | 高 |
| F-028 | カテゴリー削除可否チェック | 子カテゴリー・タスクが存在する場合は削除不可 | 高 |

---

## 6. UI/UX

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-029 | エラー Toast | バリデーションエラー等で即時フィードバック | 高 |
| F-030 | Level 4 での新規カテゴリー非表示 | 第4階層では「新規カテゴリー追加」を非表示/無効化 | 高 |
| F-031 | ドリルダウン遷移 | 直感的な階層ナビゲーション | 高 |

---

## 7. データ永続化

| ID | 機能名 | 説明 | 優先度 |
|----|--------|------|--------|
| F-032 | MMKV 永続化 | Zustand persist ミドルウェアで Store 全体を MMKV に同期 | 高 |

---

## 機能依存関係（開発順序の目安）

```
Phase 1: 基盤
  F-032 (永続化) → データ構造・Store 基盤

Phase 2: カテゴリー・タスク CRUD
  F-001, F-002, F-003, F-004, F-005 (カテゴリー)
  F-006, F-007, F-008, F-009, F-010, F-011, F-012 (タスク)
  F-025, F-026, F-027, F-028 (バリデーション)

Phase 3: タイマー・ログ
  F-013, F-014, F-015, F-016, F-017 (タイマー)
  F-018, F-019, F-020, F-021 (ログ・期間ビュー)

Phase 4: 手動入力・編集
  F-022, F-023, F-024 (手動入力・履歴編集)

Phase 5: UI 仕上げ
  F-029, F-030, F-031 (Toast, Level4制限, ナビ)
```
