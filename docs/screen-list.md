# 画面一覧 (Screen List)

## 概要
Expo Router（ファイルベースルーティング）に基づく画面構成。
参照: [requirements.md](./requirements.md), [feature-list.md](./feature-list.md)

---

## 1. 画面構成図

```
(ルート) /
  ├── index           … ルート画面（階層0）
  ├── category/[id]   … カテゴリー詳細（Level 1〜4）
  ├── history         … 稼働履歴・期間ビュー
  └── (その他)
```

---

## 2. 画面一覧

### 2.1 ルート画面（階層0）

| 項目 | 内容 |
|------|------|
| パス | `/` または `/(tabs)/` 等 |
| 説明 | ルート直下のカテゴリー・タスク一覧を表示 |
| 表示要素 | カテゴリー一覧、タスク一覧（アクティブ＋アーカイブ）、新規カテゴリー追加、新規タスク追加 |
| 遷移先 | カテゴリータップ → `/category/[id]`、履歴 → `/history` |

---

### 2.2 カテゴリー画面（Level 1〜4）

| 項目 | 内容 |
|------|------|
| パス | `/category/[id]` |
| 説明 | 指定カテゴリー直下の子カテゴリー・タスク一覧 |
| 表示要素 | 子カテゴリー一覧、タスク一覧、新規カテゴリー追加（Level 4 では非表示）、新規タスク追加 |
| 遷移先 | 子カテゴリータップ → `/category/[子ID]`、戻る → 親画面 |
| 制約 | Level 4 では「新規カテゴリー追加」を非表示または無効化 |

---

### 2.3 稼働履歴画面

| 項目 | 内容 |
|------|------|
| パス | `/history` または `/(tabs)/history` |
| 説明 | 期間ごとの稼働実績を閲覧（今日・今週等） |
| 表示要素 | 期間セレクタ、タスク別・日別の稼働時間一覧 |
| 遷移先 | 戻る → 前の画面 |

---

### 2.4 モーダル・オーバーレイ（想定）

| 画面種別 | 用途 |
|----------|------|
| タスク作成モーダル | 新規タスク名入力 |
| カテゴリー作成モーダル | 新規カテゴリー名入力 |
| 手動時間入力モーダル | 日付・開始・終了時刻・タスク選択 |
| 履歴編集モーダル | 既存セッションログの編集 |
| 編集モード | 並び替え（D&D）・削除・アーカイブ・復元 |

---

## 3. ナビゲーション仕様

| 項目 | 仕様 |
|------|------|
| ドリルダウン | カテゴリータップで子階層へ遷移 |
| 戻る | ヘッダーまたはスワイプで親階層へ |
| タブ（任意） | ルート一覧 / 履歴 をタブで切り替える構成も可 |

---

## 4. ルートファイル配置（Expo Router 想定）

```
app/
  _layout.tsx      … ルートレイアウト
  index.tsx        … ルート画面
  category/
    [id].tsx       … カテゴリー画面（動的ルート）
  history/
    index.tsx      … 稼働履歴画面
```

※ 実際の構成は実装時に調整する。
