# ドメイン定義 (Domain Definition)

## 概要
本ドキュメントは、Hierarchical Time Tracker App のドメインモデルを定義する。
参照: [requirements.md](./requirements.md), [feature-list.md](./feature-list.md)

---

## 1. エンティティ一覧

### 1.1 Category（カテゴリー）

| 項目 | 説明 |
|------|------|
| 役割 | タスクを分類するフォルダ。最大4階層まで。 |
| 制約 | 子カテゴリーまたはタスクが存在する場合は削除不可。 |
| 備考 | カテゴリーごとの合計時間は表示しない（純粋な分類フォルダ）。 |

**属性（想定）**

| 属性名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| id | string | ○ | 一意識別子（UUID 等） |
| name | string | ○ | 表示名（空文字・空白のみ禁止） |
| parentId | string \| null | ○ | 親カテゴリーID。null の場合はルート直下 |
| order | number | ○ | 同一階層内の表示順 |
| level | 1 \| 2 \| 3 \| 4 | ○ | 階層の深さ（1=最上位） |

---

### 1.2 Task（タスク）

| 項目 | 説明 |
|------|------|
| 役割 | 時間計測の対象。学習・作業項目。 |
| 制約 | アクティブなタスクは全体で最大20個。 |
| 配置 | ルート（階層0）または Level 1〜4 のいずれかのカテゴリー直下に配置可能。 |

**属性（想定）**

| 属性名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| id | string | ○ | 一意識別子 |
| name | string | ○ | 表示名 |
| parentId | string \| null | ○ | 親カテゴリーID。null の場合はルート直下 |
| order | number | ○ | 同一階層内の表示順 |
| status | "active" \| "archived" | ○ | アクティブ or アーカイブ（完了済み） |

---

### 1.3 SessionLog（セッションログ）

| 項目 | 説明 |
|------|------|
| 役割 | 「いつ・どのタスクを・何分行ったか」の記録。 |
| 単位 | 1レコード = 1日分の稼働（日またぎ時は分割して2レコード）。 |

**属性（想定）**

| 属性名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| id | string | ○ | 一意識別子 |
| taskId | string | ○ | 紐づくタスクID |
| date | string | ○ | 日付（YYYY-MM-DD） |
| startTime | string | ○ | 開始時刻（HH:mm または ISO8601） |
| endTime | string | ○ | 終了時刻 |
| durationMinutes | number | ○ | 分数（正の整数） |

**制約**
- 未来の日付禁止
- 開始時刻 > 終了時刻の禁止
- 負の時間禁止
- 1回の計測は最大24時間（超えた場合は24時間に丸める）

---

### 1.4 TimerState（タイマー状態）

| 項目 | 説明 |
|------|------|
| 役割 | 計測中のタスクの状態を保持。アプリ復帰時の経過時間計算に使用。 |
| 備考 | 永続化対象。サスペンド・タスクキル後も復元可能にする。 |

**属性（想定）**

| 属性名 | 型 | 必須 | 説明 |
|--------|-----|------|------|
| taskId | string | ○ | 計測中のタスクID |
| startTime | string | ○ | 開始日時（ISO8601） |
| 備考 | 複数タスク同時稼働時は複数エントリ |

---

## 2. 値オブジェクト・定数

| 名前 | 値 | 説明 |
|------|-----|------|
| MAX_ACTIVE_TASKS | 20 | アクティブタスクの上限数 |
| MAX_SESSION_HOURS | 24 | 1回の計測の最大時間（時間） |
| MAX_CATEGORY_LEVEL | 4 | カテゴリーの最大階層数 |

---

## 3. ドメインルール（ビジネスルール）

| ID | ルール | 適用箇所 |
|----|--------|----------|
| DR-01 | アクティブタスクは20個まで | タスク追加・復元時 |
| DR-02 | 1回の計測は24時間上限。超えた場合は24時間に丸める | タイマー停止・アプリ復帰時 |
| DR-03 | 日またぎ（0時跨ぎ）の場合は2レコードに分割 | ログ記録時（自動・手動共通） |
| DR-04 | カテゴリー削除は中身が空の場合のみ | カテゴリー削除時 |
| DR-05 | タスク削除時は紐づくログも物理削除 | タスク削除時 |
| DR-06 | Level 4 では新規カテゴリー追加不可 | UI表示制御 |
